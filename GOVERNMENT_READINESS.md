# Government-readiness handover

## Direct answer

MaapSure is now a strong **government-style engineering prototype**. It is not self-declared government-certified software. Certification and statutory authority cannot be created by code alone.

## Built and tested here

- Named tester, reviewer, administrator and read-only auditor roles
- Independent approval and self-approval blocking
- Locked approved records, formal revocation and correction revisions
- Versioned OIML rules profile and governed rule-change proposals
- Nine automatic calculations and ten conditional report sections
- Required evidence before submission
- File content checks, not only filename checks
- Permanent SHA-256 chained audit trail
- SHA-256 approved-report fingerprint and public tamper check
- Public revoked-report warning
- PDF and editable Word-compatible export
- Redacted controlled data export
- Salted password hashes, login throttling, signed sessions and browser security headers
- Automated formula, incompleteness, conditional-rule and tamper tests
- Isolated end-to-end workflow test

## Required before real statutory use

1. An authorized Legal Metrology subject-matter expert must validate every clause, formula, applicability rule, wording and report field against the exact Indian use case.
2. The department must decide whether the workflow is for model approval, initial verification, subsequent verification, inspection, or a controlled combination. Required tests differ.
3. Obtain departmental approval for the report template, certificate numbering, officer roles, retention period and revocation process.
4. Replace local JSON storage with an approved managed database supporting encryption, backups, disaster recovery and high availability.
5. Replace demo users with the department identity provider, multi-factor authentication and official officer lifecycle controls.
6. Integrate an approved digital-signature or eSign service, trusted timestamps and department certificate keys.
7. Deploy only on approved HTTPS infrastructure, ideally the selected government cloud, with protected secrets and network controls.
8. Complete independent security testing, vulnerability assessment, penetration testing, privacy review, accessibility testing and CERT-In-aligned incident procedures.
9. Validate traceability integration for reference weights, laboratory equipment and calibration certificates.
10. Run user acceptance testing in real laboratories, parallel comparison against current reports and a controlled rollout with rollback.

## Design rule that must remain

AI may help explain observations, summarize evidence or draft notes. It must never silently change a formula, publish a rule version, approve a report, or make the statutory pass/fail decision.
